# 当前装配资料

`stereo_camera-alignment.json` 保存 2026-10-28 最终装配的双目对齐预览参数；文件中的 metric_geometry_enabled 为 false，不能作为正式测距通过证据。换镜头、拆装或安装姿态变化后需重新检查/标定。

`microphone_layout.json` 保存实物通道映射和测得的大致间距。它包含当时的历史软件限位记录及指向本机照片/确认材料的名称，相关现场材料未发布。**当前运行限位以 `configs/panda-final-r43.json` 为准**。头耳跟着舵机转动、身体麦克风固定，因此该文件不是一份可直接用于刚性四麦定位的完整三维坐标标定。

当前定位左耳 CH2、右耳 CH3；身体左 CH1、右 CH4 暂不控制转向。左右均以小熊自身为准。
