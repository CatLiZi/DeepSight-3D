# 头部外壳源文件位置与开发者约定

头部外壳的可编辑原文件统一放在本目录，即仓库根目录下的 **hardware/cad/head_shell/**。当前已收录用户于2026年10月28日确认的暂定核心模型 [panda_head_only_V17.blend](panda_head_only_V17.blend)，原始文件来自 `panda_blender_github.zip`，未修改模型内容。

该文件包含头部前后壳、耳部传感器结构、镜头固定件及相机、PCB、排线、线束和紧固件参考。已使用Blender 5.2.2 LTS成功读取，场景共83个对象，内部以米计量、界面显示毫米；未发现外部链接库或未打包的图片、字体依赖。打印母件与装配副本可能同时存在，不能重复导出。

配套身体模型见 [body_shell/README.md](../body_shell/README.md)，两份文件的来源与校验值见 [panda_source_manifest.json](../panda_source_manifest.json)。本次仅核对文件读取与依赖，没有重新验证打印公差、装配保持力、运动避让或声学性能；压缩包未包含对应STL/3MF。

## 文件归档位置

| 内容 | 仓库中的位置 | 交付要求 |
| --- | --- | --- |
| 可编辑设计源文件 | hardware/cad/head_shell/ | 保留所用建模软件的原生文件，例如.blend、.f3d、.FCStd或SolidWorks零件与装配文件；实体CAD在工具支持时附STEP。 |
| 尺寸图与装配说明 | hardware/drawings/head_shell/ | PDF、SVG或清晰PNG，注明安装孔、轴线、相机开孔、线缆通道和装配关系。 |
| 打印导出件与切片项目 | hardware/print/head_shell/ | 按零件导出STL或3MF，与设计源文件版本对应，并注明打印和验证状态。 |

drawings/head_shell和print/head_shell可在首次产生对应文件时创建。STL或3MF属于导出件，交付时仍应保留可编辑原文件。原生文件如依赖外部素材，应打包必要依赖，保证其他开发者能完整打开。

## 建模与接口约定

1. [source_manifest.json](../reference/source_manifest.json)保留历史机构参考的来源、尺寸和校验记录；相关STEP与Blender源文件已移出仓库。新外壳在本目录中设计，所用参考原文件另行归档，并记录版本与校验值。
2. 对外记录的尺寸统一使用毫米。若建模软件内部使用米，应注明场景单位和导出比例，并核对切片软件中的实际包络尺寸。
3. 定义模型的前方、上方、坐标原点及Yaw和Pitch轴线，说明外壳与底座之间的安装关系。
4. 安装孔距、舵盘接口、舵机外形、相机与麦克风位置应以确认的图纸或实物尺寸为依据。历史底座局部110.87×110.87×92.50毫米仅是10个零件的参考包络，不能当作完整商品的装配尺寸。
5. 设计应记录两轴转动避让、螺丝装配空间、检修方式、线缆余量、材料，以及头壳质量和重心；尚未验证的条件应保留状态说明。
6. 源文件、图纸和打印件使用相同的零件名与版本号，例如head_shell_front_v1.blend、head_shell_front_v1.pdf和head_shell_front_v1.3mf。使用英文小写与下划线，避免含糊的最终版命名。

## 每次交付附带的说明

在本目录维护一份简短的设计说明，至少写清：

- 原生文件、建模软件及版本、零件名和设计版本。
- 单位、包络尺寸、坐标方向和使用的底座参考。
- 已确认与待确认的机械接口尺寸，以及质量和重心信息。
- 对应图纸和打印导出件的路径与版本。
- 验证状态及结果，例如设计中、已导出待验证、试装通过或试打印通过。

尺寸核对、运动避让、切片或试打印尚未完成时，应明确其状态；仅完成导出不能标记为打印就绪。打印交付同时注明材料、打印方向和所用切片配置。

## 精简入库

提交必要的设计源文件、关键图纸和选定版本的打印导出件。软件缓存、自动备份、临时副本、重复参考模型、聊天截图和机器专用G-code不纳入本目录。

提交前检查文件大小和必要依赖；较大的扫描件、渲染视频或频繁变化的二进制资料另行安排存储。完整目录约定见[hardware说明](../../README.md)。
