## 本阶段必须表达的算法结构

1. 保留两条并行感知线：双目同帧采集→每眼检测/多尺度补查→跨目关联与共同注视；四路RAW→Silero人声支持/连续性恢复→分对GCC时差与方向质量→姿态对齐和条件融合→可靠声学证据。
2. 决策层改成两个**互斥主模式**，并画清模式选择入口。互斥的是控制优先级，不是关闭另一种传感器：
   - **听声主导 Audio primary**：可靠声音→核心方向与有限Yaw目标→先转向→接近后在声音范围内关联真实人脸→视觉居中/跟随。新确认声源可以打断旧视觉辅助并撤销旧轨迹。无可靠声音时不能直接选最大脸启动这一模式。
   - **视觉主导 Visual primary**：可信视觉目标优先，声音辅助可见人脸排序；安静或声视冲突时保持视觉。没有视觉拥有者时可回退到已授权的有限听声搜索。
3. 独立画出**核心声源记忆与换人保护**。它按近期有效语音时长、可靠度和新鲜度累计，不是按音量最大选人，也不是声纹识别。声音短暂停顿可以继续完成已确认有限目标；旧方向不会不断累加。显示中的1秒蓝色保留只是显示，不作为新证据。
4. 两种模式汇入同一个受限平滑控制器。视觉微调基于图像误差与图像位移速度，大偏差可大步、接近后减速；不是固定小步，也不是测得了人体真实速度。模式变化/停止/新声源接管/反馈故障有撤销旧动作的路径。
5. 画出反馈闭环：新图像回到视觉纠偏；实测舵机反馈与受约束轨迹历史回到四麦头身坐标转换。标清50Hz是轨迹指令节奏，周期位置反馈约1Hz。
6. **D1录制是旁路**：浏览器标签页画面+已有四路PCM+状态时间线→本机MP4/WAV/WebM/JSONL/ZIP。最长60秒，不另开麦克风，不自动启动运动，不自动上传。演示稿A→B→A共90词，A不动、B讲话时慢移；提词不是实际说话人真值。

## 必须保留的事实和边界

- 左右按小熊自身：CH2左耳、CH3右耳；CH1身体左、CH4身体右。耳距约13.55cm，身体对约7.55cm；4通道48kHz/16bit WASAPI RAW。
- 当前四麦是“移动耳对+固定身体对”的条件协同。身体方向必须先转换到头部坐标；无可信姿态、明显俯仰偏离或声学冲突时回退。不是六对完整三维阵列，不是原始四路波形平均，也没有可靠声学距离。
- 双目3840×1080是采集总分辨率，原始每眼1920×1080，当前对齐共同有效区约1837×1053/眼。60fps为请求档位，不宣称所有时候实收60fps。
- 两眼正常水平视差保留，共同注视点投影回各眼；不为重合画面伪造深度，正式米制距离输出关闭。
- 位置刻度/角度比例约7.407407刻度/度。Yaw控制中位2000与四麦声学参考1952不同；Yaw软件范围1500–2500，Pitch1255–1855、中位1550。这些不是直接的角度和已验收机械端点。
- 904项Python与123项前端检查是软件验证数量，不是准确率。R52已加载核对，实物双人轮流/同时讲话、遮挡、动态四麦全姿态、噪声和远距离仍需现场验收。
- SCRFD、Silero是预训练推理模块。不要画出本项目新训练的端到端网络、ASR/LLM语义理解、声纹身份识别、六对SRP-PHAT或神经跨模态注意力。
