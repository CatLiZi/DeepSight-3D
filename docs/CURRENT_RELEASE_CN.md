## R51更新

- 保留R50完整听声目标、分段到位和停止/视觉接管保护。
- 本机 HTTP / WebSocket 控制台拒绝不匹配的跨来源浏览器请求。无 `Origin` 的本地命令行客户端仍可使用；这不是对本机其他进程的身份认证。
- 适配仓库内标定板 PDF 和打包回归测试资料，修复新检出项目找不到文件的问题。
- 整理双语项目说明、基于仓库模型的结构渲染和框架图。

所有检查均在本机现有环境、模拟执行器中运行。R51源码已经验证并不代表既有运行进程自动更新；需要操作者正常重启、刷新并确认版本后再做现场测试。[验证记录](VALIDATION_R51.md)

## 启动与版本核对

请按[主README](../README.md#快速开始)中的步骤，在仓库根目录运行 `python -X utf8 .\run_server.py`。如果已有旧服务，先在原终端正常按 `Ctrl+C`；不要同时启动多个实体进程。

网页先保持自动转头关闭，确认实际加载R51、设备与两轴反馈，再进行受控复验。下载包中的双目配置只适用于原装配参考，镜头或外壳移动后应重新检查。

## 可复现交付

`tools/export_release_manifest.py --output <目录>` 只读取源码、模型、标定、配置与依赖版本，不访问硬件。环境清单不是已经通过干净安装验证的跨机器锁文件。新机器部署、GPU/驱动兼容性、机械边界和实物声源准确性仍需分别验证。
