## R52与D1更新

- “听声转头”改为声音主导：可靠声源生成有限转向目标，转近后由对应人脸进行视觉微调；新确认的声源可以撤销旧视觉跟随并接管。
- “视觉跟踪”保持视觉主导、声音辅助选人。两种主模式互斥，模式选择与传感器采集分开；仅预览不代表停止后台麦克风采集。
- 短暂停顿不取消已确认目标；长期没有新声音时，不无限期招募后来进入画面的人脸。旧模式、旧声源轮次或过期画面不能继续控制。
- D1录制保留网页画面、四路WAV、耳部两路立体声MP4和目标时间线，最长60秒，只存本机。录制按钮不启动运动。
- 英文演示文案为A→B→A三段长发言，共90词；A固定、B在自己发言时缓慢移动。页面提词与稳定的计划段落编号同步。
- 修复Windows录制导出状态文件的读写竞争。

本机已只读确认R52加载、四麦RAW与双目在线、自动动作暂停。**904项Python回归与123项前端检查通过**；实物双人切换尚未验收。[R52验证记录](VALIDATION_R52.md) · [模式说明HTML](report/primary-modes-r52.html) · [录制说明](DEMO_RECORDING_CN.md)

## 启动与版本核对

请按[主README](../README.md#快速开始)中的步骤，在仓库根目录运行 `python -X utf8 .\run_server.py`。如果已有旧服务，先在原终端正常按 `Ctrl+C`；不要同时启动多个实体进程。

网页先保持自动转头关闭，确认实际加载R53、设备与两轴反馈，再进行受控复验。下载包中的双目配置只适用于原装配参考，镜头或外壳移动后应重新检查。

## 可复现交付
