# R11：声音辅助选人，视觉持续跟随

当前本机和示例配置使用 `audio_visual_guided`。保留 `classic_audio_first`、`crowded_visual_first` 供对照；新分支直接使用双目候选池的选择结果，不再被旧路径的“最大人脸”选择覆盖。

## 当前数据链

1. 摄像头继续请求 3840×1080 MJPEG / 60 fps，两眼各保留原图。使用现有 R09 对齐映射后，算法输入各为 1836×1050。
2. 左右眼分别检测与跟踪所有人脸。跨目匹配先检查双向光流、行误差、局部纹理相关、点的分布和唯一性。可靠对应可以共同计算指向目标的射线；未匹配时使用有效单眼观察。
3. 四路 48 kHz / 16 bit WASAPI RAW 采集保持不变。先选左耳 CH3、右耳 CH2，再做语音和方向计算；CH1、CH4 不进入这些算法。
4. 本地 Silero ONNX 预训练模型判断语音活动；不进行语音识别、声纹识别或本项目模型训练。状态化 FIR 降采样和音频序号检查防止重叠窗口重复送入模型。
5. GCC-PHAT 时差计算增加多频段一致性和最近窗口的稳定性检查。过期、削顶、复制通道、模糊相关峰和电机保护期间均不提供可用方向。
6. 声音方向与全部人脸的角度区间比较。方向须稳定、候选须有明显优势，并由不同音频序号连续确认。新候选至少三次确认且持续 0.18 秒；从可见目标切换到另一目标至少 0.35 秒。
7. 安静、弱声、方向模糊或过期时保留当前视觉目标。短暂丢失等待约 0.7 秒，不返回旧坐标；同眼高重叠、方向相近、无歧义的短时编号变化可以衔接。这只是轨迹连续性，不是身份识别。
8. 共同方向经 100 ms 时间平滑，接入已有死区、范围限制和 50 Hz 连续轨迹。显示哪一眼不决定共同方向。实物反馈缺失时仍阻止动作。

## 当前的明确边界

方向跟随与米制测距分开。现有图像对齐参数可以提供近似射线方向；正式标定仍未通过，Q、米制三角化和距离输出继续关闭。没有修改标定验收门槛。两耳间距来自 CAD，耳部方向与相机光轴尚未共同标定，前后歧义和同时多人说话仍未解决。

已保存人脸照片的数字遮挡回放通过五项检查。该照片中的跨目纹理匹配没有通过，因此正确使用二维回退；共同双眼方向目前由已知几何的合成场景验证，尚不声称真实人脸空间定位已验收。另检查 18 张旧标定照片，均未检出人脸，不能用于评价人脸匹配准确率。

官方 60 秒语音样本注入 ±9 个采样点时差后，两方向通过窗口的符号均正确，角度误差 P95 约 0.32° / 0.30°。这是已知时差的模拟，不是房间实测角度精度。静音、独立白噪声和纯音各 5 秒均无最终有效方向；3 秒旧摩擦录音仍有 1 个单窗口误报，不能把人声检测视为绝对可靠。

20 秒主程序实采 994 帧，约 49.61 fps；双眼成对处理近期约 15.75 fps。四路录音 0 溢出、0 丢块。现场无人脸，不作为真人跟随效果测试。未打开舵机串口，自动转向关闭。全套 294 项测试保留 24 个失败、2 个错误，新增 29 项通过、无新增回归。

## 网页使用

打开原来的 `http://127.0.0.1:8010/`，策略为“声音辅助选人，视觉持续跟随”。“声音辅助选人”复选框控制方向参与选人；“听声转头”是无人脸时的声音搜索运动，二者不同。当前两种自动运动开关均关闭，未点击“开始”。默认连续录音关闭，采集和实时处理继续运行。

本机已选连续平滑轨迹，俯仰中心保持 1553。下一次有人在场时先检查左右目标框、声音方向、目标切换，再进行低幅度跟随。舵机物理方向、活动范围和顺滑度仍按现场观察验收。

## 模型与复现

运行时只读本地模型，不联网下载。迁移电脑时先安装已有依赖，再执行：

```powershell
python tools/prepare_speech_vad.py --download
python tools/prepare_speech_vad.py
```

下载固定官方版本并校验 SHA-256，MIT 许可证和来源记录位于 `models/`。模型缺失或推理失败时明确显示“频谱门控降级”，不会假装神经网络仍在工作。

```powershell
python tools/validate_binocular.py --new-pattern test_av_guidance.py --output ../hardware_inventory/av-guided-local-tests
python tools/probe_binocular_replay.py --source ../hardware_inventory/binocular-upgrade-20261025/before-stereo.jpg --output ../hardware_inventory/av-guided-local-replay --guided
```

本轮完整证据：`../hardware_inventory/av-guided-upgrade-20261025/`。模型来源：[Silero VAD 官方仓库](https://github.com/snakers4/silero-vad)。对照调研：[Pyroomacoustics SRP-PHAT](https://pyroomacoustics.readthedocs.io/en/stable/pyroomacoustics.doa.srp.html) 需要麦克风阵列坐标，身体尚未安装，暂缓；[TalkNet](https://github.com/TaoRuijie/TalkNet-ASD) 需要音画片段与模型链，本轮保留已有可选实现，没有增加为主路径依赖。
