# 多距离人脸检测与清晰度辅助（2026-10-24）

场景覆盖近处桌面、室内和较远会场。当前完成二维人脸检测和清晰度诊断，**没有实现当前 MF 镜头的光学自动对焦**，没有测得不同距离的检测准确率，也没有新增身份识别。

## 硬件实测

对 1BCF:0B15 查询 Windows IAMCameraControl：Focus、Zoom 的 GetRange/Get 返回 `0x80070490`，Capabilities 为 0；Exposure、WhiteBalance 支持自动/手动。本轮只查询，没有修改曝光、白平衡或硬件零点。这与商家标注的 MF 手动调焦一致。

若必须随距离改变镜头焦点，需要 AF/VCM 或其他调焦执行机构，并由双目模组的控制板和固件提供对应接口。软件裁切、放大、锐化或清晰度分数不能补上该机构。

入口：`tools/probe_focus_controls.ps1`。记录：`../hardware_inventory/focus-upgrade-20261024/camera-controls.json`。接口说明：[Microsoft GetRange](https://learn.microsoft.com/en-us/windows/win32/api/strmif/nf-strmif-iamcameracontrol-getrange)。

## 已接入的软件

- 保留 3840×1080 MJPEG 和每眼 1920×1080，先解码、分眼并纠正方向，检测直接使用该图像，避免先生成网页 JPEG 再解码给检测器。
- 本机采用已有 `models/scrfd.onnx`，没有下载模型或安装驱动；根据 ONNX Runtime 实际提供者显示 CPU/CUDA。
- 每帧保留全画面检测，补充覆盖整个画面的六块重叠区域；发现小脸后交替细查该目标区域。补充检测每 0.18 秒至多一次，映射回原坐标并按 IoU 合并重复目标，没有固定距离档位。
- 局部检测的嘴部运动在完整画面坐标系重新计算，避免局部坐标错误地访问全图历史。
- 本机最小脸高/保持阈值为画面高度的 0.04/0.03，允许较小人脸进入现有策略；不是远距离说话人识别精度保证。
- 预览 JPEG 质量由 90 调为 95。原网页增加两眼原像素 640×360 局部、相对清晰度、亮度与纹理不足提示，每秒约更新两次，可切换局部原尺寸。
- 清晰度分数仅适合同一景物、同一距离的相对比较，不是光学质量合格线。对焦控制不可用时明确显示手动调焦，没有虚假的自动对焦开关。

## 验证与边界

同一侧脸样本，原 MediaPipe 未检出，本地 SCRFD 检出一张，得分约 0.601。这是单帧对照，不能外推准确率或近远距离效果。

模型预热后 15.019 秒收到 497 帧（33.09 fps）；近期处理 19.31 fps，四路录音 720960 个采样帧，0 缓冲溢出、0 录音队列丢块，退出后设备释放，串口从未打开。场景以室内背景为主，不是会场多人性能测试。正式测量等待模型至少完成十帧后开始；首次冷启动记录保留但不作为稳定运行结果。

新增 11 个视觉测试通过；全套 183 项仍有原先 24 个失败、2 个错误，没有新增回归。不同距离、画面位置、光照下的检测与清晰度需要现场实测；身体麦克风、深度标定和声学精度不在本次结论内。
