# R50 听声目标角度换算

本次仅修复持久听声目标的几何换算与分段到位，不修改视觉追踪、四麦时差、人声阈值、50Hz轨迹或舵机行程。源码升级不代表正在运行的8010进程已加载；以 `/api/state` 的 `algorithm_revision` 为准。

## 原问题

R49把 `audio_seek_max_step / audio_seek_full_scale_deg` 当作刻度/度。fast为220/45，而用户提供的规格500→0°、1500→135°、2500→270°对应2000/270。旧比例用于一步步接近时只是增益，用于保存最终目标时会缩短转角；旧 `audio_seek_window` 还会截短较大的目标。

## 当前规则

保存目标 = 声音观测时头部位置 + 左转符号 × 物理刻度/度 × 头部坐标声源角。

- 物理比例复用现有 `audio_capture.body_yaw_units_per_degree`，使身体→头部方位变换与听声目标采用同一个比例。当前为2000/270≈7.407407；字段名字保留兼容，但该比例也是双耳独立听声转向所需的几何。
- 当前中位1952，30°左向目标2174、右向1730；45°为2285/1619。数值取整误差不超过半刻度，不是实物精度声明。
- 最终目标只按1404–2500软件行程裁切；`goal_limited`说明是否触及软件边界。
- 每次提交独立受档位步幅限制：fast最多220刻度，stable最多160刻度，同时不超原单段窗口。速度、加速度、加加速度与平滑轨迹不变。
- 短句结束后保留有限目标，等待当前段完成，再继续剩余段。不会把旧相对声源角反复加到当前位置。
- 停止、视觉接管、配置/几何变化、反馈故障继续撤销动作权限；历史位置不是新的声音证据。
- 比例缺失、非有限或不在配置允许范围内时，清除旧几何目标并明确显示原因，不猜测旧增益。未标定的设备需先设置真实规格或实测比例。

## 验证与限制

公开仓库包含 `tests/test_core_yaw_geometry.py` 与 `tools/validate_geometry_holdout.py`，可复现已知角度和240组固定种子几何模拟。本机原始录音与私人诊断材料没有上传。所有执行器均为模拟，没有实体转动。

比例来自用户提供的舵机规格，还不是最终装配的实测角度标定。身体方向的俯仰限制仍保留；本次不宣称动态四麦、声音角度精度或机械边界已通过。

## 最短现场复验

1. 操作者正常重启8010程序并刷新网页，先保持自动控制暂停，核对R50与两轴反馈。
2. 在已验证安全范围内，不用量角工具，在小熊明确左/右两侧说短句，每侧3次；讲话约1秒后停说，观察是否继续到位，有无重复累加、卡住或异常动作。
3. 再换一个更偏侧面的位置各做一次，只标左右、不假定30°或45°，核对最终反馈与目标；由操作者按停止键，确认剩余段不会继续。
4. 双模式下可见人脸保持视觉优先。若出现偏差，保存同次的实际站位、方向、目标/反馈和原始日志；不要立即调大声音角度或速度。

以上是复验计划，尚未执行。当前无量角工具，仅验证左右、完成转向和停止行为。精确角度验收暂缓；测试代码中的30°/45°是直接注入的已知模拟角度，绝不是用户目测录音的真值。
