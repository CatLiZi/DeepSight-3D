01 · 这次解决什么

旧流程将已锁定的可见人脸持续作为控制拥有者。另一方向虽能显示声音，仍可能因为“视觉优先”没有接管转动。两个勾选框也没有明确区分谁主导，造成选择与控制不一致。

听声转头

声音主导 · 视觉可被打断

可靠声源决定绝对转向目标；转近该方向后，从声音扇区内寻找人脸。视觉负责精细居中和连续跟随。新确认声源可以撤销旧视觉动作并重新接管。

视觉跟踪

视觉主导 · 声音辅助选人

沿用稳定视觉目标选择；可靠声音帮助在可见人脸中选人。没有声音或声音与可见目标不匹配时，仍保持视觉跟随。

02 · 听声模式的数据与控制流程

① 四麦人声与方向复用现有 VAD、时差质量和姿态转换
→
② 确认核心声源按语音时长、可靠性和近期证据形成目标
→
③ 完成有限转向沿原平滑轨迹分步接近；短暂停顿不取消目标
→
④ 视觉修正只接受声源范围内的新鲜人脸，双目共同跟随

新声源确认 → 打断④ → 返回③。后台画面携带声源编号与控制轮次；旧画面不能把已经失去控制权的人脸重新交给电机。

声音位置是带误差的水平估计，不是身份识别或声学测距；人脸大小仍只表示相对视觉大小。

03 · 规则与边界

情况R52 行为
无可靠声音，但画面有人听声模式等待声音，不自动挑最大人脸；视觉模式仍可跟随。
转动中说话结束完成已经确认的有限目标，不将历史相对角反复叠加。
转近声源方向进入约 ±12° 的接近范围后，按声音扇区（默认 ±15°，使用整张脸的角度区间）关联新鲜人脸。需连续画面确认。
声音已停，尚未找到脸到达附近后保留约2秒的人脸获取窗口；窗口结束保持该方向，等待新声音。不会无限期把后来路过者当作旧说话人。
已经关联的人脸继续移动使用原有动态速度与平滑控制跟随，声音短暂停顿不会让其丢失控制权。
另一可靠声源确认撤销旧视觉轨迹，转向新声源；不因旧人脸还在画面中而拒绝切换。
人脸短暂遮挡 / 丢帧不使用旧像素继续追赶；约0.7秒内等待同一目标恢复。长时间丢失且没有新声音，不恢复旧位置搜索。
停止 / 模式切换 / 舵机故障沿用原有撤销、反馈与行程保护。切换模式清除旧控制目标；未重新获得新证据不开始旧动作。
双目自检明确失配听声定位可继续，视觉辅助控制停用，避免用失配画面驱动微调。

05 · 一分钟现场复核

  1. 正常重启并 Ctrl+F5 刷新，确认 R52。先检查两轴反馈，再开启摄像头与“听声转头”。
  2. A与B在两侧，先由A正常讲话，观察转向与人脸微调。A停说，B讲话；旧人脸仍可见时，应转向B。
  3. B缓慢移动，看视觉辅助是否跟随；A重新讲话，观察新声源是否能接管。
  4. 换成“视觉跟踪”重复简短对照，确认安静时仍可视觉跟随。
  5. 使用60秒录制保存画面、四路音频与决策时间线。左右是小熊自身左右，不把大致站位当精确角度。
