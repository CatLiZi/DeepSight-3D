# R49 辅助语音恢复

> 历史R49记录：语音恢复已包含在后续源码中；实际加载版本和现场验收请看 [R51交付说明](CURRENT_RELEASE_CN.md)。

保留原R48路径；新增同一固定Silero模型的交错有限上下文恢复通道。两个辅助状态组相差4秒，各每8秒更新，仅使用当前最多192毫秒PCM窗口中的实测支持分。

主通道默认0.50保持。辅助策略从共享AudioDecisionPolicy派生，默认可靠语音0.70，用户调高到更高值则两条路径同步提高要求；额外要求相干频谱包络变化和原双麦定位证据，至少max(3,required_audio_hits)个新窗口、跨120毫秒。录音开关不重置语音历史；采集故障、重开、时钟倒退会清理辅助状态。重复PCM不能累积确认。

原路径可靠输出逐字段保留，辅助只补空缺。原始PCM、不加噪/不混音，不将处理后的相位送入GCC。摄像头、双目几何、运动规划、舵机行程和刻度比例不变。无新模型、无训练、无硬件动作。

页面展示主通道当前窗支持、辅助当前窗支持、实际恢复要求，以及语音/方向/控制三个阶段的只读原因。神经分数与累计可用窗口都不是识别准确率。

现场正常/低音调仍需重启后的受控复测。原主通道对部分合成谐波的误报保留为已知未解决项，不能将“辅助零新增”写成“整个系统零误报”。远距离、真实转动噪声、多人和测距也未因此验收。
