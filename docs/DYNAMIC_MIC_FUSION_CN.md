# R47 四麦动态坐标融合

> 范围说明（2026-11-05）：本页保留原阶段设计与验证记录。当前R52整套路径以[算法架构说明](ALGORITHM_ARCHITECTURE_R52_CN.md)为准；视觉优先仅是两个互斥主模式之一，不能用于解释听声主导的接管规则。

> 历史R47记录：R50起听声目标也使用同一物理偏航比例。当前状态见 [R52交付说明](CURRENT_RELEASE_CN.md)。

身体左CH1/右CH4固定，左耳CH2/右耳CH3随头转动。水平近似采用：头部坐标声源角 = 身体坐标声源角 - 头部相对身体Yaw角。角度左为正。不是四路波形平均，也不是完整三维阵列或声音距离。

已修复周期反馈更新与总线缓存分离；移动中使用反馈约束的轨迹历史，在音频窗口中点取姿态。反馈不可信、历史不足、变化过快或明显俯仰未标定时，保留声学辅助与双耳，不硬拼错误角度。舵机动作提交、轮询节奏、50Hz轨迹和行程不变。

## 实机启用所缺的数据

已按用户提供的500→0°、1500→135°、2500→270°配置 body_yaw_units_per_degree=2000/270，正前方反馈参考设1952（此前用户确认的装配正前方）。该值来自用户提供的舵机规格，未独立测量实际转角；后续可用三点工具复核。原控制增益和行程不变。

后续精化仍需要真实的“位置刻度—物理Yaw角”对应，不能使用追踪增益。请提供舵机订单的具体角度规格，或后续在现有安全行程内测量正前方和左右各一个角度的静止反馈。把数据给助手即可计算，无需手改程序。网页新增“实测正前方反馈刻度”；留空时兼容使用配置中位。

开发工具 tools/calibrate_array_yaw.py 读取 JSON 数组，每行是 [实际反馈刻度, 实测左正右负角度]。至少3点且含正前方与左右两侧。未附伪造的实机测量示例。工具默认只生成拟合报告；加 --apply-config 才会保存比例和零位，同时备份原配置，并拒绝方向冲突和越界。它不驱动舵机。

## 验证范围

762项代码回归、90项前端检查、52组独立模拟通过；4625个真实录音窗口与R46输出完全一致。实机动态角度仍待标定和现场验证。所有模拟角度均为已知测试输入，不能当作实测标定值。
