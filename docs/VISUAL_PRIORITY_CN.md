# R12：视觉主导、声音扇区辅助和分段逼近

本机和示例配置当前选用 `visual_priority`。R11 的 `audio_visual_guided` 与更早两套策略保留作对照。本说明对应 2026-10-26 用户确定的取舍。

## 选谁、朝哪里转

- 没有可靠声音时，优先选择视觉中较大的可信人脸。人脸面积只是远近的近似，不是实际距离；同一个人被两眼看见不会计算成两倍面积。
- 已有可见目标时保持连续性。另一个目标明显更大（至少 1.25 倍面积）且持续出现，才考虑切换；小幅面积变化不会频繁换人。
- 声音只提供搜索扇区，默认水平角 ±15°，网页可设为 5–30°。比较的是整张脸的角度区间，而不是只检查鼻尖或人脸中心。
- 扇区里有多张脸时，优先较大者；面积差小于约 12% 时再比较声音与人脸区间、中心的接近程度。
- 声音候选须经过至少三次不同音频序号、至少 0.18 秒确认；换人再要求至少 0.35 秒持续证据与 0.6 秒当前锁定时间。
- 扇区内没有实际可见的人脸、声音不稳定或数据过期时，以视觉为准。没有视觉观察不会从声音虚构人脸坐标。
- 短暂丢失等约 0.7 秒，不输出旧坐标。等待期间不会立即按声音改向；实物仍可能完成此前已经接受的短轨迹。

“声音扇区内有可见人脸”视为声视有对应；“声视冲突”指声音扇区找不到可信可见人脸。最终转向位置始终取新视觉观察，声音角度不直接覆盖可见目标的位置。

## 画面中心为零度

继续使用现有去畸变、对齐和共同裁切，不修改标定文件。新增方向参考系，把对齐画面中心旋转定义为 0°，内部约定左为正、右为负，网页显示为“左/右多少度”。方向标签、声音扇区和控制误差使用同一参考。

角度按当前内参与射线计算，不把像素位置简单线性乘以 112°。有效视野从实际裁切计算；例如声音在右 67°，它的 ±15° 区间可能已经在画面外，此时保留视觉，不强行匹配。图像零点是坐标约定，不代表耳部与相机的物理朝向偏移已标定。正式距离与 Q 仍关闭。

## 不知道距离时怎样连续靠近目标方向

采用图像误差反馈：新画面 → 计算目标偏离中心的程度 → 有界小步调整 → 重新观察。不是把几个猜测距离依次代入。

每轴根据偏差选择较大、中等、精细调整上限；在当前单次最大 30 刻度时，三个上限为 30、12、4。实际步长还受到误差比例、死区和轴范围限制。画面已经过中心或进入死区时，抑制旧平滑值继续推头。

新视觉路径的左右、上下纠偏符号与手动方向键一致，保留镜像配置开关。每一帧新检测只纠偏一次，基于当前规划位置重新生成连续轨迹。换目标清空旧误差平滑。底层继续使用 50 Hz 五次多项式，保持位置、速度和加速度连续，并限制速度、加速度和 jerk。该方法不需要米制距离；实物舵机反馈和机械限位保护继续有效。

## 参考方法与验证范围

参考 [Chaumette 与 Hutchinson 的视觉伺服教程](https://faculty.cc.gatech.edu/~seth/ResPages/pdfs/ChaHut07.pdf) 中根据图像特征误差持续反馈的思想。本项目使用面向两轴转头的有界增量比例控制，未实现完整六自由度交互矩阵，也没有宣称对实际机构的全局收敛保证。

保留已有 Silero VAD 和 GCC-PHAT；两耳目前主要估计占主导的声源方向，不能可靠分离同时多人说话。多峰、频段不一致或不稳定时回退视觉。完整四麦几何定位仍待身体结构与各咪头位置确定。

本轮 30 项新增测试通过，全套 324 项仍保留 24 个失败、2 个错误，无新增回归。真实保存照片的五种数字遮挡检查通过。六阶段合成选人回放和包含 120 ms 延迟、15 Hz 视觉、50 Hz 连续轨迹的虚拟闭环通过范围、速度、加速度和轨迹连续性检查；这些不是实物顺滑度或房间角度精度验收。

15.05 秒实采 746 帧，约 49.58 fps；双目成对处理近期约 14.51 fps。四路音频没有溢出和录音丢块，测试中未打开舵机串口。现场两眼各检出 1 张人脸；未控制发声、遮挡或动作，不把本次采集计作多人选人或物理跟随验收。默认自动转头仍关闭，镜头仍为 MF 手动调焦。
