# V17 头部实物适配（2026-10-23）

已接入新双目、耳部两路定位与四路原始采集。身体两个咪头暂不进入方向、人声门控或 ASD 单声道输入。自动听声转头和视觉转头保持关闭，直至舵机供电、位置反馈与轴向核对完成。

## 接口与通道

- 摄像头：VID 1BCF / PID 0B15，3840×1080 MJPEG，请求 60 fps，当前实际约 33 fps。
- 采集板：YDPI4MIC，VID EF09 / PID 459D，音频接口 MI_00；本次另一个串口为 COM5 / MI_02，禁止当作舵机接口。
- 舵机板：USB-SERIAL CH340 / COM3，VID 1A86 / PID 7523；最初 ID 0 和 ID 2 回应了位置查询。小幅测试中反馈中断，尚未完成正反方向确认。没有据此更改 yaw/pitch sign。
- 本次逐耳识别确认：**左耳 CH3，右耳 CH2**（人头自身左右，USB 数据从 1 编号），**CH1、CH4 不参与算法**。依据是 RAW 四通道录音中先右耳后左耳的轻擦事件，且与用户提供的中间两个接口接线图相符。

## RAW 共享采集修正

普通共享流的四路几乎相同，逐样点仅有约 1 个 PCM 刻度的差异。每个流设置 PortAudio `eStreamOptionRaw=1` 后，四路可独立变化，逐耳识别得以成立。

因此新增 `audio_capture.wasapi_raw=true`：仍为 **WASAPI 共享 / 4 通道 / 48 kHz / 16 bit PCM**，只对本程序的流绕过系统音效处理，不修改全局注册表或系统音效开关。sounddevice 0.5.x 通过 CFFI 原生流描述设置该选项；不支持时明确报错，避免悄悄退回混合信号。该入口已单独测试，兼容性应随 sounddevice/PortAudio 升级复测。

## 耳部定位

从四路缓存先选择 `[CH3, CH2]`，再计算能量、频谱语音相似度门控和带限 GCC-PHAT。采用右耳到达时间减左耳到达时间，正角度表示人头左侧。物理时差边界由两耳间距推导，并支持通道固定时延补偿。低音量、削顶、疑似复制通道、不明确的相关峰、音频间断或过期均返回 unknown。

名义耳间距 **131.7624 mm**，来自 V17 软垫参考中心；名义镜头中心间距 **82.08 mm**。模型网格坐标已读取，变换为单位矩阵，并用头壳 STL 尺寸交叉核对量纲。它们是 CAD 几何参考，**不代表声学中心、内外参或测距已经标定**。两耳只输出水平左右方位，不能单独解决前后歧义、俯仰或声源距离。

四通道原始 WAV 继续保留以便以后使用；`recent_mono_audio()` 只从两耳派生，身体通道不会混入说话人分析。`localization_ready` 还要求当前信号有效，关闭旧 VAD 开关不能绕过失效检查。频谱门控不是训练过的人声识别模型，混响、环境噪声与角度精度需要后续实测。

## 摄像头适配

实物安装后两半画面均倒置；本机设置 `left_rotation=180`、`right_rotation=180`。分别分离再旋转，避免旋转整幅拼接图导致左右目互换。原始 3840×1080 MJPEG 不被覆盖，模型输入使用修正后的 1920×1080 单眼图像。

新增 `tracking_eye=auto|left|right`。自动模式优先左半幅，左半幅全白或全黑时可使用有效右半幅；两路都无效时清除目标并报告异常。当前仍为二维检测；双目测距、内外参和硬件同步精度尚未标定。不能用名义镜头间距直接生成可信深度。

## 舵机

新增开始转头前的位置同步：读取实际反馈作为连续轨迹起点，不从配置中的 1500 推测实物当前姿态。反馈缺失或超出配置边界时阻止启动动作。换端口或 ID 后需要重新同步。

`probe_head_direction.py` 只在实测初始位置附近偏移少量刻度，再发送返回初始位置指令，不做回中或扫全程。此次 ID 0 的测试未产生足够背景位移，随后两轴查询无回应，因此不能确认轴向、返回位置或物理顺滑度；已停止动作，待检查供电和连接后继续。初始能查询到 ID 不代表整机运动链路已稳定。

采集复测不启动自动控制、也不打开串口。新增测试覆盖耳部信号正反方向、身体通道干扰隔离、ASD 输入、RAW 流选项、异常音频拒绝、图像旋转/回退，以及舵机起点和反馈失效。完整历史测试仍有原先的失败项，详见 `hardware_inventory/stage2-head-20261023/test-results.json`，不宣称全套测试通过。

原始诊断与录音见 `hardware_inventory/stage2-head-20261023/`。15 秒主程序收到 498 帧（33.1576 fps），四通道录得 721920 个采样帧，0 缓冲溢出、0 录音丢块；双目画面有效，模型处理近期约 26.47 fps。本次为室内背景场景，不能外推为多人或说话人识别性能。
